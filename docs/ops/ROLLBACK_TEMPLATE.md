# Rollback Template

Use this template for every deployment or release task.

## Deployment Target

Describe the environment, host, service, or artifact target.

## Change Summary

Describe what is being released.

## Preflight Checks

List commands or manual checks required before deployment.

## Deployment Commands

List exact commands planned or run.

## Verification

List commands, health checks, or smoke tests used to confirm success.

## Rollback Trigger

Define what condition requires rollback.

## Rollback Commands

List exact rollback commands or restoration steps.

## Owner Notes

Record who executed the task and any handoff notes.
