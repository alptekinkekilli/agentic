# Session Close Checklist

Use this before ending any agent session.

- [ ] Current task is in `.queue/done/` or `.queue/failed/`.
- [ ] Changed files are listed in `docs/patches/PATCH_REGISTRY.md`.
- [ ] Validation commands and results are recorded.
- [ ] Follow-up tasks are created when work is incomplete.
- [ ] No agent-private context is required to understand the handoff.
- [ ] Next step is explicit and bounded.

## Closeout Record

For each session, append a short note to `docs/sessions/SESSION_LOG.md`.
